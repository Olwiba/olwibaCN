## Installation

<InstallationTabs name="sonner" />

Built on the [Sonner](https://sonner.emilkowal.ski) library. The registry item keeps the `sonner` name, so existing install commands continue to work.

## Usage

```tsx
import { Toaster } from "@/components/ui/sonner"
import { toast } from "sonner"
import { Button } from "@/components/ui/button"
```

<LiveUsageCode name="sonner" defaultCode={`<Toaster />\n<Button onClick={() => toast("Event has been created", { description: "Sunday, December 03, 2023 at 9:00 AM" })}>\n  Show Toast\n</Button>\n<Button onClick={() => toast.success("Successfully saved!")}>Success</Button>\n<Button onClick={() => toast.error("Something went wrong")}>Error</Button>`} />

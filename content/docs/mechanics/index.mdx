---
title: Mechanics
description: Headless behaviour wrappers. No visual identity of their own - they manage state, events, and interaction patterns, delegating all styling to their children.
---

## All Mechanics

| Component | Description |
| --- | --- |
| [Alert Dialog](/docs/mechanics/alert-dialog) | A modal dialog that interrupts the user with important content |
| [Collapsible](/docs/mechanics/collapsible) | Expands and collapses a section of content |
| [Command](/docs/mechanics/command) | Fast, composable command palette |
| [Context Menu](/docs/mechanics/context-menu) | Displays a menu at the pointer's position on right-click |
| [Dialog](/docs/mechanics/dialog) | A window overlaid on the primary window |
| [Drawer](/docs/mechanics/drawer) | A panel that slides in from the edge of the screen |
| [Dropdown Menu](/docs/mechanics/dropdown-menu) | A menu that opens from a trigger |
| [Hover Card](/docs/mechanics/hover-card) | Reveals content when hovering over a trigger |
| [Menubar](/docs/mechanics/menubar) | A horizontal menu of triggerable submenus |
| [Navigation Menu](/docs/mechanics/navigation-menu) | A navigation menu with support for submenus |
| [Popover](/docs/mechanics/popover) | Floating content panel anchored to a trigger |
| [Resizable](/docs/mechanics/resizable) | Panels that can be resized by dragging |
| [Scroll Area](/docs/mechanics/scroll-area) | Custom scrollable container |
| [Sheet](/docs/mechanics/sheet) | A slide-out panel anchored to a screen edge |
| [Toast](/docs/mechanics/toast) | Toast notification system |
| [Tooltip](/docs/mechanics/tooltip) | Floating label that appears on hover |

All components use [Lucide React](https://lucide.dev) as their icon library. It ships as a peer dependency — install it once and all components share it automatically.

Browse the full catalogue and search by name at [lucide.dev/icons](https://lucide.dev/icons).

```bash
bun add lucide-react
```

```tsx
import { ArrowLeft } from "lucide-react"
```

## Introduction

`@olwiba/cn` is a custom component registry built on top of shadcn/ui patterns. Copy and paste beautifully designed components into your apps.

## Quick Start

Install components directly from the registry:

<InstallationTabs name="button" variant="url" />

Or use the shorthand:

<InstallationTabs name="button" />

## Requirements

- React 19+
- Tailwind CSS v4
- TypeScript (recommended)

## Introduction

olwibaCN is a custom component registry built on top of shadcn/ui patterns. Copy and paste beautifully designed components into your apps.

## Quick Start

Install components directly from the registry:

```bash
bunx shadcn@latest add https://cn.olwiba.com/r/button.json
```

Or use the shorthand:

```bash
bunx shadcn@latest add @olwibacn/button
```

## Requirements

- React 19+
- Tailwind CSS v4
- TypeScript (recommended)

## Rolling presets

A preset is a window recomputed from "now" each time it is applied. Store the
preset id rather than the dates, and "Last 7 days" keeps meaning the last seven
days on the next visit instead of freezing on the dates it first resolved to.

```tsx
const [preset, setPreset] = useSearchParam("range") // e.g. "7d"
const range = resolveDateRangePreset(preset) ?? customRange
```

Pass your own `presets` to change the list, or `presets={false}` to hide it.

```tsx
const presets: DateRangePreset[] = [
  { id: "1h", label: "Last hour", range: (now) => ({ from: subHours(now, 1), to: now }) },
  ...defaultDateRangePresets,
]
```

## Notes

- **Ranges are staged.** Calendar picks apply on Apply, so a half-picked range
  never reaches your handler. Presets apply immediately.
- **Picked days become whole days.** A range runs from the start of its first
  day to the end of its last day.
- **`max` stops the range at that moment.** With `max={new Date()}`, future days
  are disabled and a range ending today ends now, not at midnight.
- **Months are calendar months.** "Last 3 months" from 31 May starts on
  28 or 29 February, not 3 March.
- **Two months side by side, one on small screens.** Override with
  `numberOfMonths`.
- **Helpers are exported:** `resolveDateRangePreset`, `normaliseDateRange` and
  `formatDateRange`, for resolving presets in a loader or labelling a range
  elsewhere.

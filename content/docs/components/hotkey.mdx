## Usage

```tsx
import { Hotkey, useIsMac } from "@/components/ui/hotkey"
```

Pass a shortcut string (`mod`, `shift`, `alt`, `ctrl` + key). Renders ⌘ on Mac, Ctrl on Windows/Linux.

```tsx
<Hotkey shortcut="mod+T" />
```

```tsx
<Hotkey shortcut="mod+K" asKbd />
```

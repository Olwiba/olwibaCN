## Usage

Uses theme primary colors. Fires from bottom-left and bottom-right corners; use `centered: true` for bottom center. Safe to call multiple times.

```tsx
import { fireConfetti } from "@/lib/confetti"
```

```tsx
fireConfetti()
```

```tsx
fireConfetti({ centered: true })
```

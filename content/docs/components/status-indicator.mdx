## Usage

```tsx
import { StatusIndicator } from "@/components/ui/status-indicator"
```

<LiveUsageCode
  name="status-indicator"
  defaultCode={`<StatusIndicator tone="success" pulse>Operational</StatusIndicator>`}
/>

Use `StatusIndicator` when you need a generic live/online/offline signal without committing to a product-specific badge, pill, or card. It stays intentionally small:

- use it as a decorative dot inside your own shells and badges
- add children for an inline text label
- add `aria-label` when using the dot without visible text

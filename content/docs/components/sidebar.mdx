## Composition

`Sidebar` is the primitive navigation system. Compose it with your own header, user menu, and navigation data to build a full application shell.

The interactive preview uses `layout="embedded"`, `mobileBreakpoint={0}`, and `sidebarPosition="contained"` so the sidebar stays inside the demo frame. Omit those options for a normal full-page application shell.

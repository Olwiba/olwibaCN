## Notes

- **Controlled or uncontrolled.** Stepping writes through the prototype's value
  setter and dispatches `input`, so React sees the change either way.
- **Bounds disable the buttons.** With `min`/`max` set, each stepper greys out
  on arrival rather than letting you push past and be clamped.
- **Stepping an empty field starts at `min`** (or `0`), rather than jumping to
  plus or minus one step.
- **The buttons are not tab stops.** `ArrowUp` / `ArrowDown` already step a
  number input natively, so a keyboard user gains nothing from two extra stops
  per field.
- **`step` drives rounding.** A `step` of `0.1` formats to one decimal place, so
  repeated presses don't accumulate floating-point dust.

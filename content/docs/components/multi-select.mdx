## Notes

- **The list stays open while picking**, so several options can be toggled in
  one go. Escape or a click outside closes it.
- **Values come back in option order**, not click order, so the same selection
  always produces the same array and the same URL.
- **Chips fit the space.** By default the trigger shows as many chips as fit on
  one line, keeping room for a `+N` count of the rest, and re-measures when it
  resizes. Pass a number to `maxVisible` to show exactly that many instead.
- **Select all skips disabled options**, and Clear leaves a disabled option that
  was already selected in place.
- **For a handful of always-visible filters**, a ToggleGroup with
  `type="multiple"` is quicker to scan than a dropdown.
- **Works in native forms.** Pass `name` and each value is submitted as its own
  hidden input.

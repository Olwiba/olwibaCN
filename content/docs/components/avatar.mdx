## Usage

```tsx
import { Avatar, AvatarImage, AvatarFallback } from "@/components/ui/avatar"
```

```tsx
<Avatar>
  <AvatarImage src="/avatar.png" alt="@olwiba" />
  <AvatarFallback>OB</AvatarFallback>
</Avatar>
```

## API Reference

### Avatar

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

### AvatarImage

| Prop | Type | Default |
| --- | --- | --- |
| `src` | `string` | - |
| `alt` | `string` | - |
| `asChild` | `boolean` | `false` |

### AvatarFallback

| Prop | Type | Default |
| --- | --- | --- |
| `delayMs` | `number` | `undefined` |
| `asChild` | `boolean` | `false` |
